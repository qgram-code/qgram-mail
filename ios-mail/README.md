# QGram Mail для iOS

Нативное iOS-приложение почты QGram на SwiftUI, собранное по макету
«Дизайн мобильного почтового приложения» (handoff из Claude Design,
`QGram Mail iOS.dc.html`, тема Nocturne, iPhone 16 Pro 402×874, тёмная тема).

- **Язык / UI:** Swift 5, SwiftUI, минимум **iOS 16.0**, iPhone + iPad.
- **Bundle ID:** `fun.qgram.mail`, версия `1.0 (1)`.
- **Данные:** пока демонстрационные (`Core/SeedData.swift` — тот же набор писем,
  что в макете). Сетевой слой подключается в `App/MailStore.swift`, места вызовов
  уже отделены от вью.
- **Отдельно от `ios/QGram`** — это второе приложение, а не экран внутри старого.

## Как открыть и собрать

```bash
open ios-mail/QGramMail.xcodeproj
```

Дальше в Xcode 15+: схема **QGramMail**, своя команда разработчика в
*Signing & Capabilities* (проект идёт без `DEVELOPMENT_TEAM`), запуск на
симуляторе или устройстве. IPA/архив здесь не собирается — по запросу это
*Product → Archive*.

Проектный файл генерируется скриптом; после добавления или удаления файлов:

```bash
python3 ios-mail/scripts/generate_xcodeproj.py
```

## Структура

```
ios-mail/
├── QGramMail.xcodeproj/         # сгенерированный проект (objectVersion 56)
├── scripts/generate_xcodeproj.py
└── QGramMail/
    ├── App/                     # точка входа, MailStore, SettingsStore, таб-бар
    ├── Core/                     # модели писем и демо-данные
    ├── DesignSystem/             # палитра Nocturne, акценты, общие компоненты
    ├── Features/
    │   ├── Mail/                 # список писем, письмо с перепиской, ящики
    │   ├── Search/               # поиск с областями и недавними запросами
    │   ├── Compose/              # новое письмо
    │   ├── Settings/             # настройки (акцент, квота, поведение)
    │   ├── Blocked/              # «отправка приостановлена»
    │   └── Onboarding/           # создание ящика и одноразовый пароль
    └── Resources/                # Info.plist, Assets.xcassets
```

## Экраны

| Экран | Что внутри |
| --- | --- |
| Входящие | крупный заголовок, поиск, плашка квоты, свайпы (архив/удалить/непрочитано), pull-to-refresh, метки вложений и переписок |
| Письмо | тема, метки DKIM/SPF/DMARC, сворачиваемая переписка, вложения, быстрые ответы, панель ответа |
| Ящики | шесть папок со счётчиками, карточка аккаунта с занятым местом |
| Поиск | области «Все ящики / текущая папка / непрочитанные», недавние запросы, пустой результат |
| Настройки | адрес и лимит отправки, **акцентный цвет**, **показ квоты**, поведение, параметры IMAP/SMTP, сброс пароля |
| Блокировка | причина ограничения отправки и действия |
| Онбординг | выбор имени ящика на `@qgram.im` и одноразовый пароль для IMAP/SMTP |

## Настройки, добавленные к макету

Обе живут в `SettingsStore` и сохраняются в `UserDefaults`, применяются сразу:

1. **Акцентный цвет** (*Настройки → Стиль*) — шесть вариантов, первые четыре из
   макета (`#9184D9`, `#7FB0D9`, `#C08A6A`, `#7FC0A0`). Цвет и производные от него
   оттенки (заливка 14 %, обводка 45 %, светлый текст) считаются в `AccentTheme`,
   поэтому меняются кнопки, точки непрочитанного, полоса квоты, активная вкладка,
   кнопка написания письма и подсветка выбранной папки.
2. **Показ квоты на главном экране** (*Настройки → Поведение*) — выключает плашку
   «Отправлено сегодня» над списком писем. В самих настройках лимит отправки
   остаётся виден всегда.

Рядом лежат остальные переключатели из макета (свайпы, группировка в переписки,
превью на экране блокировки) и раздел «Демо-состояния» — он показывает экран
блокировки отправки и позволяет пройти онбординг заново.

## Отличия от прототипа

- Иконки — SF Symbols вместо SVG-путей макета: те же формы, но родная для iOS
  оптическая настройка и вес.
- Свайпы и pull-to-refresh сделаны штатными `swipeActions` / `refreshable`
  вместо ручной обработки жестов — поведение и цвета кнопок (архив `#5D5294`,
  удалить `#C0392F`) совпадают с макетом.
- Клавиатура в окне письма — системная, а не нарисованная.
